# Delta Team Project

The Delta team will be making a event planner web application (BringIt!) that allows users to host, search for, and join events. Within these events, the hosting user can add items that they want guests to bring to their event (e.g., paper plates, utensils, food items, etc.), and guest users can mark themselves down to bring said items.

## Tech Stack

* **Frontend:** JavaScript, HTML, CSS, jQuery, Bootstrap
* **Backend:** Java, Spring, SpringBoot, JDBC, Maven, JSPs
* **Database:** MySQL

## Usage

* Build WAR file via a Maven build with the goals of "clean install"
* Locate the generated WAR file under the target directory
* Deploy the WAR file within a server that supports Apache Tomcat 9.x.x+

For the information of my team, in case you are unfamiliar with what these steps are and what they mean, these videos can help you.
* Building WAR file and deploy on server: https://www.youtube.com/watch?v=XifQp_Wlzjc&t=406s
* Install Apache Tomcat (servlet engine that supports JSPs): https://www.youtube.com/watch?v=d8BAQ_zRmYY
* Install Eclipse IDE for Web Development: https://www.youtube.com/watch?v=moQDW7NFpsg
* Clone Git repo into Eclipse IDE (although this if for a Java project, the process will be the same for web project): https://www.youtube.com/watch?v=cSwZ-iXY9Nw
